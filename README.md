# The Plan · แผนมดแดง

Mot Dang's pitch deck as one static page: a business plan in twelve dimensions, for an audience of robots.

- Live: https://motdang.net/the-plan/ · mirror https://nanobotco.github.io/the-plan/
- `deck/` — the slides, one `<section>` per file on a 1920×1080 canvas, and `deck.json` for the order
- `tools/slides.py` — writes `deck/slides/`
- `tools/build.py` — builds `docs/` for GitHub Pages; with `SITE_URL=https://motdang.net/the-plan OUT=../mot-dang/assets/the-plan` it builds motdang's copy

The plan meme on slide 4 uses a still from *Nathan for You*.
